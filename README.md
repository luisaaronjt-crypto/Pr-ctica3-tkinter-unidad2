# Unidad 2 Práctica 3: Repositorio de librería Tkinter

Repositorio con ejemplos prácticos de la librería Tkinter de Python para la materia Algoritmos y Programación.

## ¿Qué es Tkinter?
Tkinter es la librería estándar de Python para crear interfaces gráficas (GUI). Viene instalada por defecto y permite crear ventanas, botones, formularios, etc.

## Contenido del repositorio

### 1. `01_ventana_basica.py`
Ejemplo más básico. Muestra cómo crear una ventana principal, configurar su tamaño, título y color de fondo. Es la base de cualquier app Tkinter.

### 2. `02_botones_y_etiquetas.py`
Demuestra el uso de widgets `Label` y `Button`. Incluye cambio de texto dinámico y manejo de eventos con `command`. Muestra `pack()` y `config()`.

### 3. `03_entradas_y_formulario.py`
Ejemplo de formulario de registro. Usa `Entry`, `StringVar`, `LabelFrame` y validación de datos. Muestra cómo obtener datos que el usuario escribe.

### 4. `04_calculadora_simple.py`
Calculadora funcional con `grid()` layout. Usa botones, manejo de errores y la función `eval()`. Demuestra una aplicación útil con lógica.

### 5. `05_lista_y_menu.py`
Muestra widgets más avanzados: `Listbox`, `Scrollbar`, `Menu` y `messagebox`. Simula una lista de compras con agregar/eliminar elementos y menú superior.

### 6. `06_canvas_y_dibujo.py`
Uso del widget `Canvas` para dibujar figuras, líneas y texto. Incluye dibujo con el mouse, que demuestra eventos de mouse `<B1-Motion>`.

### 7. `07_gestor_tareas_app.py`
Aplicación completa que une todo lo anterior. Gestor de tareas con `Treeview` (tabla), guardado en archivo, y diseño con `Frame`. Es el proyecto final.

## Cómo ejecutar
1. Clona el repositorio
2. Asegúrate de tener Python 3.x
3. Ejecuta cualquier archivo: `python 03_entradas_y_formulario.py`
Tkinter no necesita instalación, ya viene con Python.
